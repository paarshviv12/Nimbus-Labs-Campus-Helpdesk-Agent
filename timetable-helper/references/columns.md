# Column dictionary: data/timetable.csv

| Column | Meaning | Format / example |
|---|---|---|
| batch | Student batch / section | Letter + digit, e.g. `A1`, `B2` |
| day | Weekday of the class | `Mon`, `Tue`, `Wed`, `Thu`, `Fri`, `Sat` |
| start_time | Class start | 24-hour `HH:MM`, e.g. `09:00` |
| end_time | Class end | 24-hour `HH:MM`, e.g. `10:00` |
| subject | Course name | Free text, e.g. `Data Structures` |
| room | Room or lab code | `R-201` (classroom), `L-3` (lab) |
| faculty | Teacher | Mock names only |

Mock data only. No student records are stored in this file.
